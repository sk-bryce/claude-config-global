# Agent configuration

These instructions apply to every agent session in this repository.

## Writing rules

- Markdown uses ASCII punctuation only: straight quotes, a plain hyphen for dashes, and three
  periods for an ellipsis.
- A document that draws on external pages ends with a `## References` section that lists each
  page it used.
- Keep lines under 100 characters.

## Checks

- Run `scripts/scrub-check.sh` on a file before you commit it.
