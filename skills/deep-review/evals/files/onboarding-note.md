# Onboarding Notes

Welcome to the team. This note covers the first-week setup.

## Accounts

Request access to the shared drive and the ticket tracker on day one. Both go
through the same intake form. Acess to the staging environment is granted after
the security training is complete.

## Environment

Install the toolchain from the internal package index, then run the bootstrap
script from the repository root. If the bootstrap fails on a fresh machine, the
usual cause is a missing system dependency; the script prints which one.

## Who to ask

Post in the team channel rather than direct-messaging. Questions asked in the
open get answered faster and the answer stays searchable.
