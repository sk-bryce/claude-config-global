# Spec Backlog

Artifact categories named here are deliberately unscoped: intentionally brief stubs, not
designs, for capabilities this config has not built. Expanding one into a full spec happens only
once it is actually being built; when that happens, decide first whether it warrants a dedicated
authoring skill (modeled on `skill-author`) or is simple enough to be direct content plus
reference docs.

## Learning / Teaching / Knowledge Base

- Intent (rough): capture and retrieve durable knowledge for reuse across sessions.
- Open questions: what is stored, where, and how it is retrieved; overlap with `reference/`.

## Code Review
