# Cyberdecks

A cyberdeck is a custom-built, portable computer, usually assembled by hand from a
single-board computer, a self-contained display, a keyboard, and a battery, and housed in a
builder-made enclosure rather than a laptop shell. The name descends from William Gibson's 1984
novel *Neuromancer*, where a "deck" was the fictional hardware hackers used to jack into his
invented data network; today it names a real, active DIY hardware hobby with its own
communities, contests, and a wide range of practical and artistic use cases.

This documentation set covers what cyberdecks are, where the idea came from, how people build
and use them today, and how to plan and build your own.
